# 🌙 Полночный Аркан

Таро в Telegram: бот и Mini App с раскладами, подпиской за звёзды, рекламой и админкой.

## Что умеет
- **9 раскладов**
  - простые (бесплатно 3 в день): Карта дня, Да/Нет, Прошлое·Настоящее·Будущее
  - премиум (за 1 расклад или по подписке): Отношения, Что он(а) думает обо мне, Работа и деньги, Ситуация, Совет на неделю (7 карт), Кельтский крест (10 карт)
- **Колода Райдера–Уэйта**: 78 настоящих карт (общественное достояние), лежат в `webapp/cards`
- **Монетизация через Telegram Stars**
  - 👑 подписка «Безлимит»: 199 ⭐ в месяц, все расклады без лимита и без рекламы
  - 🔮 пакеты раскладов: 5 / 15 / 50 за 49 / 119 / 299 ⭐, не сгорают
  - 🎁 за приглашённого друга +3 расклада тебе и ему; новичку 2 в подарок
- **Реклама на странице расклада**: карточка с фото, текстом и кнопкой; подписчики её не видят
- **Ежедневная «Карта дня»**: бот присылает каждое утро (выключается в профиле или `/daily off`)
- **Картинка расклада для сторис**, звуки, вибрация, история раскладов в облаке Telegram
- **Админка в боте** (`/admin`): статистика, выдача безлимита, возвраты звёзд, реклама

Карты тянет сервер и проверяет лимиты, поэтому обойти оплату из приложения нельзя.
Каждый запрос из Mini App подписан Telegram (`initData`), сервер проверяет подпись.

## Как устроено

```
server.py            сервер (aiohttp) + бот (aiogram) в одном процессе
webapp/index.html    Mini App
webapp/cards/        78 картинок карт
render.yaml          настройка сервера на Render
.github/workflows/   «будильник», чтобы бесплатный Render не засыпал
```

Где это работает (всё бесплатно, как «Сюрприз дня»):

| Что | Где |
|---|---|
| Сервер, бот и Mini App | Render, разворачивается из репозитория |
| База данных | Neon (PostgreSQL) |
| Чтобы Render не засыпал | GitHub Actions раз в 10 минут обращается к серверу |

## Запуск в Telegram: шаг за шагом

Нужны аккаунты на GitHub, [Render](https://render.com) и [Neon](https://neon.tech) (на Render и Neon проще войти через GitHub).

### 1. Бот в @BotFather
1. [@BotFather](https://t.me/BotFather) → `/newbot` → имя **Полночный Аркан**, username **PolnochArkanBot**. Сохрани токен.
2. `/setdescription` → например: «Таро в Telegram 🌙 Карта дня, расклады на любовь, работу и судьбу. 3 расклада в день бесплатно.»
3. `/setabouttext` → «🌙 Расклады Таро прямо в Telegram»
4. `/setuserpic` → аватарка (можно взять любую карту из `webapp/cards`, например `m18.jpg` — «Луна»)
5. `/setcommands` →
   ```
   start - Сделать расклад
   daily - Карта дня: on / off
   paysupport - Помощь с оплатой
   terms - Условия
   ```
Твой Telegram ID подскажет [@userinfobot](https://t.me/userinfobot).

> Токен — это пароль от бота. Не публикуй его и не загружай в репозиторий: он вводится только в настройках Render.

### 2. Код на GitHub
1. GitHub → **New repository**, например `polnoch-arkan` (можно приватный).
2. **Add file → Upload files** и перетащи из папки проекта:
   `server.py`, `requirements.txt`, `render.yaml`, `README.md`, `.env.example`, `.gitignore`, папку `webapp`, папку `.github`.
   **Не загружай** `.env`, `.venv`, `data`, `.claude`.
3. Если папка `.github` не загрузилась (браузер иногда пропускает скрытые папки): **Add file → Create new file**,
   имя `.github/workflows/keepalive.yml`, вставь содержимое одноимённого файла.

### 3. База на Neon
1. Neon → **New project**, регион Frankfurt.
2. Скопируй **Connection string** (`postgresql://...?sslmode=require`).

### 4. Сервер на Render
1. Render → **New → Blueprint** → выбери репозиторий. Render прочитает `render.yaml`.
2. Заполни переменные:

| Переменная | Что вписать |
|---|---|
| `DATABASE_URL` | строка подключения из Neon |
| `BOT_TOKEN` | токен бота |
| `ADMIN_IDS` | твой Telegram ID (несколько — через запятую) |
| `SUPPORT_CONTACT` | куда писать по оплате, например `@твой_ник` |

`WEBHOOK_SECRET` Render сгенерирует сам, адрес сервера сервер узнаёт сам.

3. **Apply.** Через пару минут адрес будет вида `https://polnoch-arkan.onrender.com`. Сервер сам создаст таблицы, поставит вебхук и кнопку «🔮 Расклад» в меню бота.

### 5. Будильник
GitHub → репозиторий → **Settings → Secrets and variables → Actions → Variables → New variable**:
`API_URL` = адрес сервера на Render. Затем **Actions → «Будильник для сервера» → Run workflow**.

### 6. Mini App-ссылка (по желанию)
@BotFather → `/newapp` → выбери бота → URL = адрес сервера на Render, short name `tarot`.
Получится ссылка `t.me/PolnochArkanBot/tarot`, которая открывает приложение сразу.

### 7. Проверить
1. Напиши боту `/start` — придёт кнопка «🔮 Сделать расклад».
2. Сделай расклад, открой профиль, купи что-нибудь (звёзды можно сразу вернуть через админку).
3. `/admin` — откроется админка.

## Админка (`/admin`)
- **📊 Статистика**: пользователи, новые за сутки, расклады, подписки, выручка, возвраты
- **👑 Выдать безлимит**: id, @username или пересланное сообщение → +7 / +30 / +90 дней, «навсегда» или «забрать».
  Быстро: `/give @username 30` (0 = навсегда)
- **💸 Платежи и возвраты**: выбрать покупку → «Вернуть звёзды». Расклады списываются, автопродление подписки отключается.
  Покупки человека: `/refund <id>`
- **📢 Реклама**: фото с подписью (или текст) → ссылка → текст кнопки → предпросмотр → «Запустить». Показы, клики, CTR.
- `/cancel` — выйти из заполнения формы

Доступ — только у ID из `ADMIN_IDS`.

## Локальный запуск
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python server.py --dev
```
Открой http://localhost:8080. Без `DATABASE_URL` используется SQLite (`data/tarot.db`); покупки в DEV зачисляются сразу.
С настоящим ботом локально: заполни `.env` (`BOT_TOKEN`, `BOT_MODE=polling`) и открой Mini App через https-туннель
(`cloudflared tunnel --url http://localhost:8080`, адрес — в `WEBAPP_URL`).

## Где что менять
- Цены пакетов: `PACKS` в `server.py`; цена подписки, лимиты, бонусы: переменные окружения (см. `.env.example`)
- Какие расклады бесплатные: `SPREADS` в `server.py` и флаг `premium` в `index.html`
- Значения карт: `MAJOR` / `RANKS` в `index.html`

## Ограничения бесплатных тарифов
- **Render free** засыпает без запросов; будильник держит его активным. Если всё же уснул, первый запрос просыпается ~минуту, Telegram повторит вебхук сам.
- **GitHub отключает расписание**, если в репозитории 60 дней не было коммитов — тогда запусти «Будильник» вручную.
